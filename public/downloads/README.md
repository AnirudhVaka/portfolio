# /public/downloads/

The pre-built DOCX resume lives here.

There is **one comprehensive resume for everyone** — no per-region variants.
It includes every experience bullet and every section (all the detail).

Generated by `scripts/build-docx.ts` at build time:

```bash
npm run build:docx
```

File produced:

```
anirudh-vaka-resume-universal.docx   Comprehensive · all bullets + all sections
```

The "Download Word" button on `/resume` links directly to this file.

PDFs are not pre-built — visitors press "Print / Save as PDF" on `/resume`,
which uses the browser's print-to-PDF with our `@media print` CSS. This
avoids bundling a ~200MB puppeteer dependency and lets the visitor pick
paper size + margins.

## Two build paths

```bash
# Path 1 — Node + tsx + the `docx` npm package (canonical, used by `npm run build`)
npm run build:docx

# Path 2 — Python + python-docx, no npm required
npm run build:docx:py
```

> Note: the Python path (`scripts/build_docx.py` + `scripts/dump-data.mjs`)
> has not been updated for the single-resume change and may still emit
> per-region output. `npm run build` uses Path 1, which is the source of truth.
