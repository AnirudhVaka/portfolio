# /public/downloads/

Pre-built DOCX resumes — one per region — live here.

Generated by `scripts/build-docx.ts` at build time:

```bash
npm run build:docx
```

anirudh-vaka-resume-anz.docx    Australia / NZ (2–3 pages, Skills in Demand)
anirudh-vaka-resume-global.docx Global / Remote (1 page tight, no visa line)

The "Download Word" button on `/resume` links directly to these. Each
button is region-aware via the active variant.

PDFs are not pre-built — visitors press "Print / Save as PDF" on
`/resume`, which uses the browser's print-to-PDF with our @media-print
CSS. This avoids bundling a 200MB puppeteer dependency and lets the
visitor pick paper size + margins.

## Two interchangeable build paths

Both produce structurally identical .docx files. Pick whichever fits
your environment:

```bash
# Path 1 — Node + tsx + the `docx` npm package (canonical)
npm run build:docx

# Path 2 — Python + python-docx, no npm required
npm run build:docx:py
```

Path 2 reads the same TypeScript source via Node 22's
`--experimental-strip-types`, dumps to a temp JSON, and feeds it to
`scripts/build_docx.py`. Useful in CI images that have Python but not
the Node `docx` package, or before `npm install` has run.
